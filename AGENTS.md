# Правила проекта

После каждого завершённого обновления сайта проверить изменения, создать коммит и отправить его в origin/main: https://github.com/cofeechik/agrodrone-services.
Пользователь явно разрешил загрузку файлов сайта, фотографий и размещённых контактов. Это правило касается только этого проекта.
Не применять force push, не включать секреты и не перезаписывать чужие изменения. Если отправка невозможна, сообщить причину.
GitHub-репозиторий остаётся приватным. Публичный запуск сайта требует отдельного запроса.
Использовать реальные изображения техники. Не придумывать отзывы, клиентов, показатели работы и цены. Форма готовит сообщение WhatsApp, а не отправляет заявку на сервер.
