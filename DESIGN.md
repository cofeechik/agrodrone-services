# Дизайн

Референсы, просмотренные при аудите: DJI Agriculture, XAG P150 MAX, CLAAS, Leica Geosystems, Stripe, Linear, Teenage Engineering, Basecamp, Monzo. Для текущего сайта взяты принципы крупной технической фотографии, нейтральной основы с одним акцентом и последовательной иерархии. Фирменные элементы и готовые макеты не копируются.

Палитра: белый #ffffff, графит #202423, терракота #d34425 для акцентов и интерактивных состояний, светлый нейтральный #f3f4f0 для техники, тёмный #242c28 для контактов. Шрифт Golos Text с кириллицей, локально; лицензия OFL в assets. Manrope сохранён как резервный файл и не загружается страницей.

Структура: задача и расчёт на первом экране; два основных направления с фотографиями и два компактных дополнительных; техника с четырьмя параметрами; порядок работы; три вопроса; контакты и форма. Повторяющийся рекламный блок удалён. Не добавлять разделы только ради длины страницы.
Фотографии производителя не выдаются за портфолио команды. Перед публичным запуском проверить права использования.

Кадрирование: для опрыскивания фокус по вертикали 28% / 24% на мобильном; для внесения 22% / 13%. Проверять все винты и рабочий модуль на 320, 390, 768, 1024 и 1440 пикселях. Не заменять фотографии без повторной проверки.

Движение: одно вступление фотографии дрона на первом экране за 650 мс; фотография остаётся видимой на протяжении анимации. Остальные секции не скрываются и не появляются последовательно. Небольшой сдвиг стрелок, увеличение фото 2.5% только при наличии hover, прерываемое раскрытие FAQ 240 мс. Нет бесконечного движения, параллакса и перехвата прокрутки. В reduced motion движения нет, без JS содержимое остаётся доступным.

Доработка Impeccable: повторяющиеся подписи над заголовками удалены; межбуквенное расстояние не плотнее -0.04em. Стрелки — единая SVG-геометрия, состояния меню и FAQ — линии CSS. Контактные ссылки и меню имеют область нажатия не менее 44 px, поля — шрифт 16 px. Цвет каретки и выделения согласован с палитрой; числа характеристик табличные. Подпись производителя размещена непосредственно у фотографий услуг.

Форма: получатель явно указан — Бурабаев Сайранбек. Для опрыскивания и внесения обязательны площадь и культура; для остальных услуг они необязательны. Услуга и расположение обязательны всегда. Ввод из пробелов отклоняется. После подготовки сообщения показываются локальный статус и повторная ссылка; при редактировании устаревшая ссылка скрывается. Не показывать статус «отправлено»: сообщение отправляет посетитель в WhatsApp. В браузере данные не сохраняются между обновлениями.

Проверка детектора: cramped-padding на equipment-section/contact-section, specifications и шагах процесса — известные ложные срабатывания по вложенным контейнерам. У секций есть вертикальные отступы 48–68 px и горизонтальные отступы container 18–100 px; у строк характеристик 12–15 px, у мобильных шагов 19 px. Не добавлять дублирующие отступы и не отключать правило глобально ради чистого отчёта.
