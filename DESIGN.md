# Дизайн

Референсы, просмотренные при аудите: DJI Agriculture, XAG P150 MAX, CLAAS, Leica Geosystems, Stripe, Linear, Teenage Engineering, Basecamp, Monzo. Для текущего сайта взяты принципы крупной технической фотографии, нейтральной основы с одним акцентом и последовательной иерархии. Фирменные элементы и готовые макеты не копируются.

Палитра: белый #ffffff, графит #202423, терракота #d34425 для акцентов и интерактивных состояний, светлый нейтральный #f3f4f0 для техники, тёмный #242c28 для контактов. Шрифт Golos Text с кириллицей, локально; лицензия OFL в assets. Manrope сохранён как резервный файл и не загружается страницей.

Структура: задача и расчёт на первом экране; два основных направления с фотографиями и два компактных дополнительных; техника с четырьмя параметрами; порядок работы; три вопроса; контакты и форма. Повторяющийся рекламный блок удалён. Не добавлять разделы только ради длины страницы.
Фотографии производителя не выдаются за портфолио команды. Перед публичным запуском проверить права использования.

Кадрирование: для опрыскивания фокус по вертикали 28% / 24% на мобильном; для внесения 22% / 13%. Проверять все винты и рабочий модуль на 320, 390, 768, 1024 и 1440 пикселях. Не заменять фотографии без повторной проверки.

Движение: появление на 18 пикселей за 600 мс один раз, небольшой сдвиг стрелок, увеличение фото 2.5% только при наличии hover, раскрытие FAQ 240 мс. Нет бесконечного движения, параллакса и перехвата прокрутки. В reduced motion движения нет, без JS содержимое остаётся доступным.
