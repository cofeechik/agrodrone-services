# Агродрон

Сайт услуг с помощью XAG P150 MAX. HTML, CSS и JavaScript. Сборка и установка пакетов не нужны.

## Просмотр и редактирование

Откройте `index.html` в браузере. Содержание находится в `index.html`, оформление в `styles.css`, логика в `app.js`, фотографии в `assets/`.

## Заявки

Форма готовит сообщение для WhatsApp. Посетитель сам отправляет сообщение. Серверной отправки и хранения данных нет. Основной номер задан в `siteConfig.whatsapp` в `app.js`. Контакты в HTML взяты из предоставленной презентации; перед запуском проверьте их принадлежность проекту.

## Расширение

Секции имеют идентификаторы `services`, `equipment`, `process`, `contact`. Можно добавлять страницы услуг, кейсы, второй язык и серверную форму. Кабинета, базы данных и системы заявок сейчас нет.

Название «Агродрон» и знак «+» используются как рабочее оформление до утверждения названия компании. Фотографии настоящего XAG сохранены локально. Источники перечислены в `assets/SOURCES.md`.
