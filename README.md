# Агродрон

Сайт услуг с помощью XAG P150 MAX. HTML, CSS и JavaScript. Сборка и установка пакетов не нужны.

## Просмотр и редактирование

Откройте `index.html` в браузере. Содержание находится в `index.html`, оформление в `styles.css`, логика в `app.js`, фотографии в `assets/`.

## Заявки

Форма готовит сообщение для WhatsApp Бурабаеву Сайранбеку. Посетитель сам отправляет сообщение. Серверной отправки и хранения данных нет. Для опрыскивания и внесения нужны площадь, культура и расположение; для доставки и карт площадь и культура необязательны. После подготовки появляется повторная ссылка, если WhatsApp не открылся. Основной номер задан в `siteConfig.whatsapp` в `app.js`. Контакты в HTML взяты из предоставленной презентации; перед запуском проверьте их принадлежность проекту.

## Расширение

Секции имеют идентификаторы `services`, `equipment`, `process`, `contact`. Можно добавлять страницы услуг, кейсы, второй язык и серверную форму. Кабинета, базы данных и системы заявок сейчас нет.

Название «Агродрон» и знак рядов поля используются как рабочее оформление до утверждения названия компании. Фотографии настоящего XAG сохранены локально. Источники перечислены в `assets/SOURCES.md`.

## Движение и доступность

Одно короткое вступление фотографии дрона на первом экране; фото услуг слегка увеличиваются при наведении; вопросы раскрываются за 240 мс и реагируют на повторные нажатия. Анимации отключаются при `prefers-reduced-motion`. Остальные секции видны сразу, без JavaScript содержимое и прямые ссылки WhatsApp доступны. Меню и вопросы доступны с клавиатуры. В контактах разделены звонки и переходы в WhatsApp, области нажатия увеличены для телефона.
# Интерактивный 3D-прототип

Новая версия для проверки сценария — `prototype.html`. Текущий `index.html` сохранён.

Запуск из папки проекта: `node tools/serve-prototype.cjs`, затем открыть http://127.0.0.1:4173/prototype.html. Всё загружается локально, включая Three.js; сборка и интернет для просмотра не нужны. Двойной клик по HTML показывает резервный рендер, но браузер не разрешает загрузить 3D-модули через file://.

Сценарий: центральная модель → выбор применения с фотографиями XAG → характеристики с выделением бака, верхнего блока и винтов → обращение в WhatsApp. Сменные модули не подменяются в нашей модели RevoSpray. Кнопка остановки и режим уменьшенного движения доступны. Источники и план: `PROTOTYPE.md`, `assets/SOURCES.md`, `assets/vendor/three/README.md`.

Браузерная проверка: Chrome с программным WebGL, 1440/1024/768/390/320 px, четыре узла винтов, выделение частей, сценарии, подготовка сообщения без отправки, reduced motion, ошибка загрузки GLB. Нет горизонтального переполнения и ошибок JS в проверенных состояниях. Скорость на реальных мобильных устройствах ещё не измерена. Публикация не выполнялась.
