Native origin is the upper attachment plane, front −Y, Z up. Web Y up, front +Z. Runtime position `[0,0.48375,-0.075]` is raw glTF aircraft coordinates before recentering. Cargo replaces both spray and spread systems plus the old gear; it is not stacked over a tank. The web model has a deliberately shortened suspended rope for inspection, prominently disclosed in service copy. Actual required rope length is 5–15 m; the displayed arrangement is not an operating setup. No inside electronics were invented.
