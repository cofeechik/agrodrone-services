# XAG P150 MAX — первая версия 3D-модели

Модель для будущей визуализации на сайте. Конфигурация RevoSpray, раскрытые лучи и винты.
Это реконструкция внешнего вида по фотографиям, а не заводская CAD-модель.

## Масштаб и источники

Единица модели — метр. Официальная [спецификация XAG](https://xa.com/en/p150max/p150maxspecs): диагональ между двигателями 2.335 м, диаметр винта 1.600 м, четыре двигателя, бак RevoSpray 80 л.
Остальные размеры и внутреннее устройство приблизительные: восстановлены по фронтальным и диагональным фотографиям.

Рабочие ракурсы: `01-xag-official-front.png`, `02-xag-official-spec-view.png`, `04-agrifuture-top-front.jpg`, `09-airstrike-top-oblique.webp` из локальной папки `tmp/xag-p150-reference` вне репозитория. Чужие фотографии в модель и веб-экспорт не включены.
Файл, ранее подписанный как страница с размерами, на деле содержит слайд о применении дрона; его не использовали как размерный чертёж.

## Файлы

- `build_model.py` — воспроизводимый исходник для Blender; создаёт отдельную сцену, сохраняя исходную.
- `export_model.py` — экспортирует только модель и переводит созданные надписи в геометрию для GLB.
- `xag-p150-max-v01.blend` — редактируемая модель и студийная сцена.
- `xag-p150-max-v01.glb` — самостоятельная модель для веба, без студийных камер и света.
- `preview-three-quarter.png` — проверочный рендер.
- `preview-front.png` — фронтальный ракурс для сверки с фотографиями.
- `render_previews.py` — создаёт оба проверочных рендера.

Корпус, бак, лучи, фиксаторы, двигатели, винты, посадочные опоры и распылители разделены по объектам. Каждый винт имеет отдельный `ROTOR_ANIMATION_ROOT`. Студия находится в отдельной коллекции и не экспортируется.

## План доработки

1. Первая версия: масштаб, силуэт, базовые узлы, материалы, проверочный рендер и GLB.
2. Сверка силуэта с дополнительными фронтальным, верхним и задним ракурсами; уточнение бака и корпуса.
3. Точная форма шарниров, креплений, распылителей, проводки и маркировки. Коррекция деталей, для которых сейчас нет размеров.
4. Проверка нескольких ракурсов, оптимизация геометрии и материалов, затем подключение к сайту с плавным поворотом и статичным запасным изображением.

В первой версии нет анимации складывания, инженерной точности скрытых узлов, проверенного объёма бака или финальной оптимизации GLB. Сайт пока не меняется.
