# RevoCast 5 / P5 — selected photo references

Researched 2026-10-08. Ten distinct references for **XAG P150 Max RevoCast 5**, also called **RevoCast P5** by XAG Australia. Originals are retained without resizing, cropping or upscaling. Model/UI files were not changed.

## Start here

Use the four XAG Australia studio photographs first: **02** shows the disc-facing end; **05** shows the opposite end; **03–04** show complementary oblique sides. All four are 1200×1200 with a white background. The source explicitly identifies the module as P150 Max RevoCast P5, model M4RCP115BH.

**10** is the strongest clean side profile, 3840×2582. It is byte-identical to the existing `tmp/xag-p150-reference/13-revocast-agrifuture.jpg`, now catalogued with its direct original URL. **07** helps with the disc hub/ribs; **11** supplies the higher-resolution screw/drive arrangement. **09** and **13** help with top/lid shape.

Front/rear terminology is deliberately not guessed: the two end elevations are labelled by the visible disc or drive motor. Align these with XAG's native user-manual diagram on page 11.

## Provenance and generation checks

- [XAG Australia module gallery](https://shop.xag-au.com/products/revocastp5): four actual studio views explicitly labelled RevoCast P5 for P150 Max.
- [Official XAG P150 Max](https://www.xa.com/en/p150max): details taken specifically from its **RevoCast 5** section, not neighbouring RevoSpray sections.
- [Agrifuture RevoCast 5](https://agrifuture.tech/products/xag-p150-max-revocast-5-with-screw-feeder-l): side profile and feeder cutaway. The slug says L; current product data names M. This does not change the verified system generation, but screw-size identity should not be inferred from the slug.
- [Drone Culture P5 cover](https://droneculture.com.au/products/xag%C2%AE-p150m-revocast-p5-container-cover): explicit P150M RevoCast P5 component title.

[manifest.json](manifest.json) records every original image URL, source page, publisher, dimensions, file size, SHA-256, view description and image type. File hashes and decoded pixels were checked; repeated compositions were also compared visually.

Removed three downloaded duplicate alternatives: the smaller XAG Australia side render and feeder cutaway, and SkyFlow's enlarged/reencoded side render. Original existing workspace references remain untouched. RevoCast 4/P4/P3 and old P100/RevoCast 2 search results were excluded, including unrelated recommendation tiles on otherwise relevant dealer pages.

## Limits / manual cross-check

No verified genuine bottom-up photograph or isolated full-module overhead photograph was found. **07 is a disc-facing lower-mechanism render, not a bottom-up photo; 09 is an installed top render.** Do not treat transparent cutaways as literal exterior finish or photography.

Main supplied the XAG-published, dealer-hosted [27-page RevoCast 5 user manual](https://static.wixstatic.com/ugd/984a86_2ebf2f8dd6bb4bb88c77c12649cd514b.pdf): native PDF page 6 for components, page 11 for underside/disc/screw-axis relationships, page 23 for 1119×1012×743 mm dimensions. This task did not independently re-extract or review that PDF; the main/manual workflow owns that evidence.

These images are working references owned by XAG/dealers, not newly cleared commercial website assets.
