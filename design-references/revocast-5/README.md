# RevoCast 5 reference collection

See `photos/README.md` and `photos/manifest.json`: ten distinct original images with URLs, sizes and hashes. Four studio photos are verified as P150 Max RevoCast P5, M4RCP115BH.

The following source PDFs are saved locally in `manuals/` (excluded from Git with their derivative page cache):

- `revocast-5-user-manual.pdf`: 27 pages, XAG RevoCast 5 V1.0 EN. Actual working download: https://static.wixstatic.com/ugd/984a86_2ebf2f8dd6bb4bb88c77c12649cd514b.pdf
- `revocast-p5-specifications.pdf`: despite this initial download filename, this is the **57-page P150 MAX aircraft manual**, not a standalone RevoCast specification sheet. Source: https://static.wixstatic.com/ugd/984a86_dd19d928b27649f08d85278c8a3b5ff5.pdf

`pdf-pages/` retains native page renders, including source presentation pages 9 and 17, and the RevoCast manual's component, underside and specification diagrams (PDF pages 6, 11, 23). Original presentation remains at `F:/Downloads/XAG_P150_MAX_презентация.pdf`.

The editable exterior reconstruction and five native renders are in `../../models/revocast-5/`. No photo has been upscaled or synthesized. References are not a cleared website-image license.
